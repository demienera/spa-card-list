# MyGames App

Современное веб-приложение для просмотра каталога игр. Интегрировано с RAWG API для получения актуальных данных об играх. Поддерживает создание собственных карточек игр и управление избранным.

---

## 🎮 Основной функционал

- **Просмотр каталога игр**
- **Детальная страница игры** — полная информация об игре с описанием, скриншотами и метаданными
- **Создание карточки игры** — возможность добавлять собственные игры в каталог
- **Система избранного** — сохранение любимых игр в localStorage

## 📦 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/demienera/game-catalog-app.git

# Перейти в директорию проекта
cd game-catalog-app

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать проект для продакшена
npm run build

# Предпросмотр production сборки
npm run preview
```

## 🔑 Настройка API

Для работы приложения необходим API ключ от [RAWG](https://rawg.io/apidocs).

**Инструкция по получению ключа:**

1. Зарегистрируйтесь на [rawg.io](https://rawg.io/)
2. Перейдите в настройки аккаунта и получите API ключ
3. Создайте файл `.env` в корне проекта со следующим содержимым:
   ```
   VITE_BASE_URL=https://api.rawg.io/api
   VITE_RAWG_API_KEY=your_api_key_here
   ```
